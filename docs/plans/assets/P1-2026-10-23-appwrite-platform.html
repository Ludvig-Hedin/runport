  • Railway and Render cannot run Appwrite's hosting. It needs Docker access they do not give. Accounts, data and files still work there, so Railway runs the apps instead.

What it got right: Appwrite is a good base, do not build a cloud, and only the "create app" layer is missing.

What it costs, and what could go wrong

The Mac stage costs nothing. Online on Railway lands around 300 to 550 kr a month for a handful of apps. An estimate until the Mac stage gives real numbers.

  • The Mac runs short of space or memory. Docker capped at 8 GB, unused parts off, Appwrite stopped when idle.
  • Claude cannot create projects. About two minutes of clicks per app in Appwrite's admin. The rest stays automatic.
  • Docker is off after a restart. Turn on "Start Docker Desktop when you sign in" once.
  • An Appwrite update breaks things. Version pinned. Upgrades only on purpose.
How it is built the detail, for whoever builds it
  1. Install Appwrite 2.6.1, light setup, PostgreSQL, nightly backup.
  2. Test creating a project from code.
  3. Starter kit with server-side login, then Claude builds a todo app on it.
  4. Bun MCP tool: create, list, delete. Then two proof apps.

Not in this

  • Other users, billing or teams.
  • A self-hosted Git server. GitHub stays.
  • Custom domains per app. Each app gets a subdomain.
  • Mobile apps.
